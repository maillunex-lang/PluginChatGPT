# Lunex DevCore

Independent AI development platform for games and applications. Source Available with commercial licensing planned; current status **pre-alpha**, not production security audited.

**Owner deployment:** https://rikagro.ru/devcore/mcp (OAuth 2.1 authorization code + PKCE). Personal owner installation only. No client subscription service yet.

Implemented foundations: MCP Gateway, owner OAuth, authenticated root tools, isolated PostgreSQL project/memory/task state, initial context loader, 20 skill entries with routing, read-only diagnostics and strict automated tests. See [progress](docs/PROGRESS.md), [architecture](docs/ARCHITECTURE.md), [install](docs/INSTALL.md), [GDD](docs/GDD.md), [roadmap](docs/ROADMAP.md) and [license](LICENSE).

No paid language-model API or on-server LLM required. Intellectual development tasks still need an active ChatGPT session. A commercial license issuer, autonomous engine, full engineering toolchain, APK builder and GameLab remain roadmap items.
